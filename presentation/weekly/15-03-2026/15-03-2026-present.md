- New feature
    - **Contradiction-First Verifier Fusion**: Prioritizes contradictory evidence during verification to prevent "majority-rule" drowning of factual inconsistencies.
        - **Why**: Standard aggregators (like majority vote) fail when most retrieved documents contain the same common misconception.
        - **How**: If any piece of evidence shows a strong contradiction above a threshold, it forces a "Contradicted" status even if other sources are neutral or supportive, increasing recall for hallucinations.
    - **Citation-Aware Mitigation Router**: Dynamically selects between reranking, reprompting, and filtering based on verifier signals and evaluation objectives (e.g., factual consistency vs. citation attribution).
        - **Why**: A single mitigation strategy (like filtering) is too aggressive for minor citation errors but too weak for core factual contradictions.
        - **How**: It uses a rule-based policy to apply low-cost reranking for low-confidence claims, and high-precision filtering only for verified contradictions, balancing response quality and safety.
 
- New evaluation settings
    - **Independent Module Evaluation**: Evaluating generator and verifier separately to identify specific strengths and weaknesses of each component.
        - By verifier module and mitigation module
    - **RAGTruth Baseline & LettuceDetect on CiteBench**:
        - **Objective**: Conduct a controlled evaluation of the RAGTruth baseline and the LettuceDetect pipeline using the CiteBench multi-domain benchmark.
        - **Workflow**: 
            1. **Alignment**: Extract common sample IDs from both methods to ensure identical evaluation constraints (same queries and evidence context).
            2. **Conversion**: Adapt heterogeneous model outputs (RAGTruth QA-pairs and LettuceDetect span-predictions) into the standardized CiteEval system-eval JSON schema.
            3. **Meta-Evaluation**: Run identical automated metrics (`ca`, `ce`, `cr_itercoe`, `cr_editdist`) via the CiteEval-Auto suite to compute citation accuracy and claim-level factual consistency ratings.
            4. **Delta Analysis**: Generate automated reports (e.g., `summary.json`) that quantify the performance gap in mean answer ratings and sentence-level supportiveness.
